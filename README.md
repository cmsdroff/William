# William's Maths Practice

A single-page app to help a 10-year-old with dyslexia learn times tables and long division.

- **Times tables:** 3, 4, 6, 7, 8, 12 and Mix. Dot arrays split into two colours (easier sums), a "Show the trick" button, big multiple-choice answers, read-aloud, a colour-coded chart, and adaptive repeats of missed facts. No timers.
- **Long division:** guided one step at a time using Divide, Multiply, Subtract, Bring down, Repeat (Dad, Mum, Sister, Brother, Rover). "Watch me" and "Your turn" modes, 2 or 3 digits, optional remainders, times-table strip for the divisor.
- Dyslexia-friendly design: Lexend font, soft off-white background, wide spacing, no italics, light/dark toggle.

Everything is in `index.html`. No build step. Progress (stars, missed facts) is saved in the browser's local storage on each device
